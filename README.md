# JellyKodiSync – repozitář pro Kodi

Doplněk **Jellyfin Sync** pro Kodi 21: knihovna z Jellyfin serveru přímo v Kodi (filmy včetně verzí,
seriály), kontextové menu „Jellyfin – vybrat verzi“, přehrávač pro TMDb Helper a volitelně skin
Arctic Fuse 3 s přednastavenou úvodní obrazovkou.

Potřebuješ účet na Jellyfin serveru (adresu, jméno a heslo ti dá jeho správce).

## Instalace

1. Stáhni **[repository.jellyfinsync-1.0.0.zip](https://raw.githubusercontent.com/jellyrepo-t/kodi-jellyfin-sync/main/repository.jellyfinsync-1.0.0.zip)** (soubor nerozbaluj).
2. V Kodi: *Nastavení → Systém → Doplňky* → zapni **Neznámé zdroje**.
3. *Doplňky → Instalovat ze zip souboru* → vyber stažený `repository.jellyfinsync-1.0.0.zip`.
4. *Doplňky → Instalovat z repozitáře → JellyKodiSync repozitar → Doplňky pro video → Jellyfin Sync → Instalovat*.
5. Otevři **Jellyfin Sync** – spustí se průvodce (server, přihlášení, synchronizace knihovny, vzhled).

Aktualizace pak Kodi stahuje samo. Skin Arctic Fuse 3 a TMDb Helper se instalují od jejich autora
(repozitář jurialmunkey), tento repozitář na něj jen odkazuje.

## Obsah

- `repository.jellyfinsync-1.0.0.zip` – instalační soubor repozitáře
- `zips/` – doplňky repozitáře pro Kodi (`addons.xml`, `addons.xml.md5`, zipy)
